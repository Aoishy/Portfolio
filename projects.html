Side Channel Attack

June 2025
Python
JavaScript

The project explored side-channel attacks focusing on website fingerprinting through cache usage analysis. Timing Analysis to measure memory access delays and demonstrate cache hierarchy effects. Sweep Counting Attack to collect side-channel traces by measuring cache sweeps, visualized using Flask + Matplotlib heatmaps. Automated Data Collection to build a pipeline with Selenium + SQLite to automatically visit websites, collect traces, and store datasets. Machine Learning Classification to train CNN models in PyTorch, achieving up to 97% accuracy in classifying websites from cache traces. Collaborative dataset (50,000+ traces) to evaluate model generalization. Real-time website detection via a Flask server endpoint, returning predictions instantly. Gained hands-on experience with system security, cache-based side-channel vulnerabilities, automation, and ML-based classification.

  • Lexical Analysis: Using Lex to tokenize the input C code into meaningful symbols.
  • Parsing: Implementing a parser using Yacc to analyze the token stream and build an abstract syntax tree (AST).

This project provides hands-on experience with compiler design principles, including syntax analysis, semantic analysis, and code generation.
